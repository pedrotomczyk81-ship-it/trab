O PROJETO

UM HUB PARA
QUEM JOGA.

O GameHub é uma aplicação web de catálogo de jogos eletrônicos. Aqui é possível explorar títulos, consultar informações, filtrar por categoria e cadastrar novos jogos. Os dados ficam centralizados em memória durante a sessão, sem backend ou banco de dados.

Este projeto foi desenvolvido como atividade acadêmica para praticar conceitos fundamentais do framework Angular.

03 / SERVICES

Dados compartilhados
